## Where the GitHub Actions workflow will go

`.github/workflows/` — **not created yet** (deliberately; this task
was cleanup + review only). Planned shape for the test, for whoever
writes it: bundle once in a setup job
(`npx remotion bundle src/short-entry.tsx --out-dir=out/bundle-shared`)
and share it with all shards — **do not let each shard rebuild
`out/bundle-story`, or the ten parallel builds race on one
directory** (see the blocker above). Then a matrix of 10 shards,
each
`node scripts/render.mjs story no_friction --start X --end Y
--stills-only --no-audio --port <distinct> --bundle out/bundle-shared`,
upload each segment MP4 as an artifact (`retention-days: 1`), then
a stitch job that ffmpeg-concats the segments and muxes
`public/soundtrack.wav` once. Use `render.mjs`, NOT
`render_chunks.py` (video renderer, weaker verification, re-runs
`make_short.py` per worker).
Prerequisites the workflow needs that this repo does not provide:
a `public/soundtrack.wav` in the repo (or a sync step for it), and
ffmpeg on the runner (preinstalled on `ubuntu-latest`).
